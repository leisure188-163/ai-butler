# Design Decisions · 设计决策记录

## D1 · 产品名

- 名称：**Butler**，产品名「**AI 智能助手管家**」；产品名本身即定位句，
  不再维护第二行句式；定位「通用 AI 助手管家」，策略广度优先
- 命名与词表标准单源 [specs A1-03](specs/architecture/A1-03-命名与语言标准.md)，
  强制收编见 [conventions/3](conventions/02-命名与文案规范.md)

## D2 · 主题定位

- **纸墨（Cardstock & Ink）v5 · 中性工作台基底**：**案面安静（冷纸灰 + 墨青），
  信息是唯一主角**——真比例卡面、金箔芯片、压印卡号、墨印章、卡扇动画全部退役；
  结果形态从「印章」改**结果徽（.tag：无边框浅底）**；领取/状态用行+发丝线与
  矩阵表承载，不做 SaaS 卡片墙
- **token 值**（唯一来源 `apps/web/src/styles/tokens.css`，红线 6）：
  - 案面 `#F1F3F4` / 纸白 `#FFFFFF` / 凹槽 `#E8EBED` / 纸绳线 `#D9DEE1`
  - 墨青 `#182831`（主文本与主按钮）/ 雾墨 `#54646D` / 弱化 `#84939B`（仅装饰）
  - 文本级强调 `#8A5D14`（白底 ≈4.9:1，激活态唯一彩）；
    金箔渐变 `--chip-gold-*` 退役
  - 语义五色分两档（分类词表由 core 出产，UI 只消费五词）：
    填充 base 档 + 正文 ink 档（白底全部 ≥4.5:1）
  - **应用小徽**：身份色六值 `--card-face-1..6` 单值保留（白字对比 ≥6:1 的渐变对
    退役），按应用 id 稳定散列分派；**身份色只允许出现在 AppBadge 单值点**
- **结构（六页 IA，ADR-013）**：仪表盘 = 一句话结论 + TodoRail 三节 + 速览四行；
  应用 = 六列表册 + 虚线邀请行；账户 = 9 列矩阵（MatrixTable，待办栏已迁出）；
  流量 = 每账户一块（小徽头行 + 活跃包/历史耗尽折叠/汇总原话/流水）；
  日志 = 结果徽 + 中性表头；列表仍是「行 + 发丝线」
- **多主题（v5）**：三套并列可切换——**纸墨**（浅·默认，基底值即上列）/
  **墨夜**（深：墨青夜底 `#10181E` + 纸白 `#E8EDF0`，金与语义五色整体提亮一档）/
  **暖纸**（浅护眼：米黄纸底 `#F4ECDD` + 暖墨 `#3A3226`，语义五色向暖压深半档）。
  默认**跟随系统**（`prefers-color-scheme` 实时跟随）。
  实现纪律：覆盖块只覆写颜色类令牌（含 `--color-on-ink`/`--color-ink-strong`
  随主题翻转），字体尺寸动效继承不复制；小徽身份色跨主题一致；
  切换 = `<html data-theme>`，设置存 `butler.settings.v1`（读 `kabao.settings.v1`
  兼容迁移一次；缺省 = 跟随系统）
- **字体/动静**：沿用 D4 纪律（系统栈、数字 `tabular-nums`、标识符 mono）；
  动效仅按压反馈（scale 0.97/110ms），卡扇揭示动效退役，
  全局尊重 `prefers-reduced-motion`；无 ALL-CAPS 眉标/箭头按钮/渐变装饰

## D3 · 布局与 IA

- **左侧边栏导航 · 六页平铺（2026-11-14 裁决，[ADR-013](adr/ADR-013-六页信息架构.md)）**：
  **仪表盘（默认）/ 应用 / 账户 / 流量 / 日志 / 设置**；顶栏单行「AI 智能助手管家」
  + 拉丁标 Butler，≤900px 顶条同样显示主名
- 职责重排：待办栏三节归仪表盘，导入与「一键导入（n）」归应用页，
  领取/体检留账户页；规范 hash `#/dashboard / #/apps / #/accounts / #/traffic /
  #/logs / #/settings`，重定向表 v2（7 条）见 A3-01 v2 §3
- 提醒角标挂「仪表盘」项（待处理 + 非正常账户 + 临期凭据，条目数不去重）
- 页面状态走 **hash 直链**：可直链、可后退（ui-ux-pro-max 深链规则）
- 结论先行：仪表盘首屏只回答「今天有事要做吗？」——大字结论 + 速览四行 + 待办栏，
  不是横幅盒子
- ≤900px 顶条两行网格：主名/刷新一行、六项导航一行（横向滚动，不与主名重叠）；
  矩阵与应用册窄屏保留可读最小宽度并横向滚动
- 状态诚实：不把「已请求」渲染成「已领取」；结果渲染只消费 core 出产的分类谓词；
  待办栏只汇报系统真做过的动作
- 页面规格见 [A3-01 v2](specs/application/A3-01-信息架构与核心页面.md)
  （按 A1-03 §4 展开）

## D4 · 字体与可访问性

- M0 用系统字体栈（-apple-system/Segoe UI/Inter 回退）；中文正文优先系统字体，不引入 webfont 延迟
- 对比度按 WCAG AA；动效尊重 `prefers-reduced-motion`

## D5 · 桌面端

- Electron（非 skill 默认 pywebview）：需要托盘常驻 + 单实例锁 + 自动拉起 sidecar；
  旧仓库的 Electron 壳验证过这条路线（只作可行性依据），新壳按本仓库结构重写。
  现状（2026-11-12）：双模式（在线 WEB_URL / 离线 sidecar 拉起 + 健康轮询）已实现
  （apps/desktop/main.js）；托盘常驻与单实例锁 R2 落地
