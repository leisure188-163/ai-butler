# ADR-016 · 失效凭据只撤销管家本地副本，不动客户端会话

- **状态**：Accepted
- **日期**：2026-11-16
- **决策者**：butler 维护者
- **关联**：ADR-015（失效可见可修+熔断）、ADR-007 决策 7（登录不自动化）、
  A4-01 §1（凭据保险库）、A2-07 §5（健康联动）、A2-08 §2（调度闸门）、
  A3-01 §3（待办修复入口）

## 背景

用户要求"登录态过期后自动调用退出接口"，并进一步明确范围：**只清管家副本**，
不影响客户端/浏览器里的登录态。

真机抓取结论（2026-11-16）：

- Qoder 点「退出登录」后日志只有 `[Auth] User signed out` +
  `[AuthStore] Credential storage diagnostic {"operation":"clear"}`，没有任何
  `logout/signout` 远程请求；它清的是客户端自己的凭据存储。
- Trae CN / 豆包客户端未找到可复用的 logout HTTP 接口；WorkBuddy 是腾讯桌面
  客户端，GUI 操作不在支持范围。
- ChatGPT / Claude 网页端有 next-auth 会话，远程 signout 会同时吊销用户浏览器
  共享的会话，副作用不可接受。

因此"自动调用远程退出接口"在桌面端不成立；butler 能做且应该做的，是**在判定
登录态失效后，撤销自己库里的凭据副本**，让后续 Run 不再拿旧 token 反复打上游，
同时保留归档与审计证据。

## 决策

1. **端口**：`VaultPort.revoke(account_id, *, reason) -> int`。
   - 撤销该账户全部当前凭据：旧值先归档到 `{account}:{kind}#{seq}`
     （`vault_history` 留痕、后端仍可找回），再删除主引用；
   - `vault_items` 行保留并写 `revoked_at` / `revoked_reason`（可审计、可展示），
     不物理删行；
   - 幂等：已撤销行跳过；后端主引用已缺失也继续标记；
   - `load` 命中已撤销条目 → `CredentialRevoked`（继承 `CredentialMissing`，
     连接器仍按 NO_AUTH 处理，不会静默给空凭据）；
   - 重新 `store` 同 `(account_id, kind)` 清空撤销标记，恢复可用。
2. **触发**：`AssessAccountHealth` 在「存在 NO_AUTH 连败（含由此判出的
   `invalid/risk`）或凭据已过期（`expired`）」时自动调用 `revoke`。
   - 只看鉴权失败事实，不按最终级别误伤：`risk` 若来自其它信号（未来异常码簇）
     不触发；
   - 只在健康级别落定时触发，不在连接器执行层逐次清；
   - 撤销失败不掩盖健康结论，证据里如实写失败原因；
   - 事件 `ACCOUNT_HEALTH_CHANGED` 仍按级别变化发一次。
3. **边界**：只动 butler 自己的保险库。**不调用任何远程 signout、不删除客户端
   凭据文件、不强制客户端登出**；桌面端"退出登录"仍由用户在客户端完成。
4. **修复**：`relogin` 重试必须先重新停靠（dock）读取客户端新凭据，再发
   `POST /runs`。前端 `repairAccount` 的顺序固定为
   `POST /apps/{target}/import` → `POST /runs(account_id)`；导入未发现该账户时
   如实提示，不空跑重试。
5. **可见**：`/api/v1/accounts` 的 `CredentialOut` 带
   `revoked / revoked_at / revoked_reason`；UI 标「本地副本已撤销，等待重新停靠」，
   待办引导写明「客户端退出并重新登录 → 点重试（会先重新读取本机凭据）」。

## 后果

**正面**：

- 失效凭据不再被后续 Run 反复使用，401 噪音和无效上游请求收敛；
- 旧值归档 + 审计 + revoked 标记，证据不丢；
- 撤销范围严格限制在 butler 库内，不影响用户客户端/浏览器登录态；
- 修复路径从"点重试但仍旧 token"变成"先重新导入新凭据再重试"。

**负面/约束**：

- 撤销后该账户在重新停靠前不可执行任何需要凭据的动作（这是有意的硬失效）；
- 桌面客户端仍需用户手动退出/登录，butler 不能代劳；
- 自动撤销是健康评估的副作用：打开账户页也可能触发一次（幂等，有审计）；
- `vault_items` 保留撤销行后，健康评估必须跳过 revoked 行，否则会把已撤销
  凭据的有效期继续算成 expired。
