# ADR-023 · 显示名称列禁用 display_name 通用名

- 状态：已采纳（2026-11-17 用户裁决）
- 背景：账户域 v3 已把 `display_name` → `account_name`；平台册沿用
  `display_name` 命名与既有裁决不一致，通用名后续扩展难辨业务归属。
- 决策：凡"显示名称"性质的列，一律按业务命名（`XXX_name`）：
  账户 = `account_name`、平台 = `platform_name`；后续新增域同理
  （如调度触发器 = `trigger_name`）。禁用 `display_name`/`name` 裸通用名。
- 落地：`plat_platform` 列 `display_name` → `platform_name`（RENAME COLUMN
  幂等自迁移）；`PlatformEntry.display_name` → `platform_name`；端侧
  `/platforms` 契约字段 `display` 保持不变（SDK/前端零改动）。
