# ADR-029 · 凭据按账户隔离，会话型平台不抓 token

- **状态**：Accepted
- **日期**：2026-11-19
- **决策者**：用户（jason）
- **关联**：ADR-007（豆包界面通道裁决与零裸请求，决策 9）、ADR-008（凭据入库边界）、A2-03 §4

## 背景

用户提议「同步创建账户时把该账户的 token 也抓下来，以后切换账户就能拿到对应 token，
所有请求都不会出错」。这个诉求要按平台类型分开看——本系统里平台分两种，凭据面完全不同：

| 类型 | 判定 | 代表 | 凭据现状（2026-11-19 实测 `acc_account` + `vault_item`） |
|---|---|---|---|
| token 型 | 请求靠自己带的凭据发（HTTP API） | `qoder_cn`、`agentrouter` | 每账户一份：qoder 三个账户各 `dpapi_gcm_v10 + umid_cosy`，agentrouter 一份 `browser_session` |
| 会话型 | 请求由运行中的客户端进程自己发，签名由页面 JS 现算 | `doubao_cn`、`workbuddy_cn`、`trae_cn` | 零凭据入库（workbuddy 现解密即用、trae 无凭据） |

对 token 型，「每账户一份 token、切换即取用」**已经是既有实现**（dock 抓 → 按 `account_id`
入 vault → 请求时按账户取 + 按账户选 `base_url`）。对会话型，抓 token 不但无收益，还会毁会话：

- 豆包**没有可注入的凭据**：会话 = 运行中的客户端进程本身，`a_bogus`/`msToken` 是页面 JS
  在每次请求前现算的短时签名（PROTOCOL §1）；
- Cookie 库不可读：Chromium `v10` 加密 + 32 字节应用层前缀 + **运行期独占锁**
  （`Profile N` 被活动面板占用，`Default` 常为过期旧会话）；
- 更关键的是**裸请求会反噬**：缺签名/签名不符的连续裸请求会把会话打到受限态，
  连手工点都失败、重装才恢复（2026-11-07/08 两次事故、ADR-007 通道裁决、其决策 9 收口）。
  用户过去反复遇到的「签到失败，请稍后重试」（`710010702`）就与这条机理同族。

## 决策

**凭据按平台类型分层：token 型按账户入 vault（已是现状），会话型零凭据走界面通道，
明确不做「同步时抓 token」这一步。**

1. **token 型**（`credential_kinds` 非空的 client/web 平台）：dock 阶段抓取 → 以
   `vault_item(account_id, kind, slot)` 落库（默认槽 `default`，见 ADR-003 §6）→
   领取时按 `account_id`（多槽再按 `slot`）取用；多账户之间
   凭据物理隔离，切换账户 = 换一份凭据 + 换 `base_url`，不存在串号。
2. **会话型**（`credential_kinds` 为空 / 连接器声明零凭据）：不抓 Cookie、不抓 token、
   不落 vault。领取编排一律「读活跃身份 → 需要则切会话 → 复核 → 界面动作 → 用 detail 复查」。
3. **禁止**：任何平台不得以「拼装请求」的方式绕开凭据面（豆包 = ADR-007 决策 9 零裸请求；
   其他平台若凭据缺失，走 `NO_AUTH` + 人工重登，不降级成裸请求）。
4. **归属校验**：凡是能多账户的 token 型平台，凭据读取必须带 `account_id`，
   取不到就是显式错误（`NO_AUTH`/`StorageNotFound`），绝不回落到"第一份凭据"。

（排除项：会话型平台的「登录态」本质是客户端登录界面，重登只能人工——扫码/手机号，
不做自动化；「抓 token」对它们既不可读也不可用。）

## 后果

**正面**：

- 「切换账户后请求串号」在 token 型平台结构上不可能发生（凭据按 account_id 隔离）；
- 会话型平台不会因为抓不到 token 而误判为「功能缺失」，红线写在文档里，不再反复试错；
- 避免重蹈 11-07/08 的会话受限事故（那是"想用请求代替界面"的直接代价）。

**负面/约束**：

- 会话型平台（豆包）的多账户能力天然串行：同一时刻只有一个活跃登录态，
  切号 → 复核 → 重开活动页是唯一路径，无法并行；
- 会话型平台的「凭据健康」只能靠界面/业务码反馈推断，没有 token 过期时间可算；
- 平台新增时必须先判类型（`credential_kinds` 是否为空），判错会直接违反本 ADR。
