# ADR-030 · 账户别名绑定真实身份

- **状态**：Accepted
- **日期**：2026-11-19
- **决策者**：用户（本轮明确要求「用实际的账户而不是我们自己重新定义为 main，后续还需要给他们命名别名」）
- **关联**：ADR-003（多账户）/ ADR-025（账户编址用实际昵称）/ ADR-021（acc_account）

## 背景

ADR-025 把**豆包**的编址从 `main` 改成了实际昵称，但只覆盖了单个平台。
其余平台的存量卡仍停在 `main`（真机核对 2026-11-19）：

| 平台 | 连接器有无真实身份 | 现状 | 停在 main 的原因 |
|---|---|---|---|
| doubao_cn | 有（昵称） | 逍遥酒鬼 / Leisure520 | 已按 ADR-025 迁移完成 |
| qoder_cn | 有（`session.user.id`） | `main` | `dockio.py` 留了「兼容存量 qoder_cn:main」分支，首账户仍占 main |
| workbuddy_cn | 有（`account.nickname` 解密） | `main` | 实现有了（ADR-025 扩展），存量卡未迁移 |
| agentrouter | 有（`state.user_id`） | `main` | `adapter.py` 直接把 `account_code="main"` 写死 |
| trae_cn | **没有**（声明式连接器只有 ss_aes 凭据） | `main` | 取不到身份，任何自动方案都无解 |

用户看到 `trae_cn:main`、`qoder_cn:main` 这类卡，无法与「我实际有哪几个账户」对上号。

两条候选：

- **A. 别名（alias 列）**：不动 `account_id`，加一列用户可编辑的显示名，
  显示优先级 `alias > account_name > account_code`。零迁移风险，trae 也能用。
- **B. 改真 id**：把 main 换成真实 key，并迁移 `acc_account.id`、
  `vault_item.account_id`、`exe_claim.account_id` 三张表的引用。

B 的风险是孤儿凭据卡（漏改一张表 → 凭据指向不存在的账户，健康评估回退
到「无账户」分支，撤销逻辑却仍按老 id 走），且 trae 这类无身份平台仍然无解。

## 决策

**采用 A：加 `alias` 列，B 不在本决策范围内推进。**

1. **数据层**：`acc_account` 加 `alias TEXT NOT NULL DEFAULT ''`；
   `Account` 域对象加 `alias: str = ""`（唯一新增字段，其余字段含义不变）。
2. **写端点**：`PATCH /api/v1/accounts/{account_id}`，body `{"alias": "..."}`。
   - 长度 ≤ 40（与自定义平台名同口径）；空串 = 清除别名（显示回落到连接器给的名称）；
   - 404 账户不存在、400 过长，**显式报错不静默兜底**（红线 5）；
   - **只写 alias 一列**。改 `account_id` 是迁移动作（牵连 vault / exe_claim 外键），
     不在本端点开放——这条路留给单独的一次性脚本 + 备份。
3. **显示优先级**：`alias > account_name > account_code`（单一出口
   `useAccountRows.accountLabel`，平铺表与分组卡共用，改一处两处生效）。
4. **不可推断**：别名是**纯显示层**。不参与鉴权、不参与调度、不进 run target
   （target 仍是 `account_id`），避免「改了个名字把领取打到别的账户上」。
5. **入口**：账户详情面板（账户管理页点行展开）里的「别名」输入 + 保存；
   提示语写明「留空保存 = 清除，账户 id 不变」。

## 后果

**正面**：

- `trae_cn:main` 这类取不到身份的平台，也能标成「Trae 主号」，一眼对上是哪个号
- 零迁移风险：不动任何外键，不动 run target，历史台账不受影响
- 平台无关：任何现有/未来连接器都能用，不要求连接器必须能给出身份

**负面/约束**：

- 别名不自动跟随真实昵称：用户在客户端改了昵称，alias 仍是旧值（要靠人再改一次）
- 与 ADR-025 存在职责重叠：能取到真实身份的平台优先走 code 编址（自动），
  alias 是**取不到身份时的兜底**，不是替代品
- 改 id 的需求（B 档）仍然悬空：qoder/workbuddy/agentrouter 的存量 main 卡
  依旧显示 `main`，需要用户决定是否单独做一次带备份的迁移
