# ADR-009 · 矩阵重构与品类句调整

- **状态**：Accepted
- **日期**：2026-11-13
- **决策者**：用户（方向 C 账号矩阵 + 四项收窄裁决）+ Agent 落地
- **关联**：ADR-007（品牌与词表）、A3-01（信息架构）、design-decisions D1/D2/D3、红线 2/6

## 背景

竞品（doubao、workbuddy 等 AI 助手应用）界面均为极简风格；卡包当时的
「卡纸与墨 v4」视觉（真比例卡面/金箔芯片/压印卡号/墨印章/首页卡扇动画）
装饰多、信息密度低，且品类句「你的 AI 卡包」强调"卡"而非"AI 替你打理"。
产品初衷是「一人多账号 × 多应用平台的繁琐操作统一化」，最贴此初衷的
界面形态是**账号矩阵**，而非卡片收藏册。

候选方向：A 极简工作台 / B 管家对话面板 / C 账号矩阵。用户选定 C，
并以四项裁决收窄：四页（矩阵即首页）、常驻待办栏（重叙事）、
中性基底+应用小徽、层① web 全做 + 层② 多账号 ADR 占位（ADR-010）。

## 决策

三项裁决（2026-11-13 起）：

1. **IA 四页化，矩阵即首页**：六页（首页/卡包/雷达/记录/提醒/设置）收敛为
   **账号 / 用量 / 记录 / 设置**；账号矩阵 = 默认页与产品本体（应用 × 账号
   一屏：状态/今日动作/额度/凭据/最近操作 + 行内动作 + 批量）。
   首页与卡包并入矩阵页；提醒页三节聚合并入常驻待办栏（TodoRail，
   聚合口径不变）；雷达改名「用量」。旧 hash 直链（#/home、#/wallet、
   #/card、#/alerts、#/radar）静默重定向，不断桌面壳与收藏夹。
2. **品类句换新**：「Kabao · 你的 AI 卡包 / AI Card Wallet」退役，改为
   **「Kabao · AI 账号管家」/ "Kabao · AI Account Butler"**。
   产品名 Kabao（卡包）与 ADR-007 其余词汇继续有效。
3. **视觉去卡化**：真比例卡/金箔芯片/压印卡号/墨印章/卡扇动画退役；
   中性工作台基底 + **应用小徽**（身份色单值点，唯一合法身份色载体）；
   结果形态从「印章」改「结果徽」（.tag）。三主题机制与主题名不变
   （卡纸与墨/墨夜/暖纸，默认跟随系统），只调值；语义五色与
   signal 单源纪律（红线 2）、token 单源（红线 6）不变。

「AI 管家」身份感的落定形态：**自动化三态叙事**（已自动完成 / 需要你处理 /
即将到期，TodoRail 承载）——系统只如实汇报真做过的动作，不做对话式
假 AI（诚实纪律优先于体验噱头）。

## 后果

**正面**：

- 界面与竞品简洁度对齐；「多账号一眼看清 + 一键批量」直击产品核心价值。
- 契约零改动（全部数据来自既有端点），门禁九项可直接回归。
- 矩阵行 = 账号，天然兼容 ADR-010 的多账号领域扩展（多账号 = 多行）。

**负面/约束**：

- 「卡包」钱包隐喻的视觉识别度下降，品牌独特性由名称与品类句承载。
- AccountsPage 496 行超 400 软警戒（600 硬上限内）——拆分挂账记 STATUS，
  下一次触碰该页时优先拆 MatrixTable 子组件。
- 旧「卡纸与墨」主题名沿用但视觉含义已变（中性基底），文档需随改（T12）。
