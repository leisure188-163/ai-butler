# ADR-013 · 六页信息架构

- **状态**：Accepted
- **日期**：2026-11-14
- **依据**：用户裁决（2026-11-14）：页名级换词随六页 IA 一次到位；词表 v2 见
  [A1-03 §3](../specs/architecture/A1-03-命名与语言标准.md)。
  （历史设计书/任务书 docs/superpowers/ 已于 2026-11-14 按用户清理要求删除）
- **落地文档**：[A1-03 §4](../specs/architecture/A1-03-命名与语言标准.md)、
  [A3-01 v2](../specs/application/A3-01-信息架构与核心页面.md)
- **编号说明**：任务书 T11 预留编号 ADR-012，但 2026-11-14 同日
  [ADR-012](ADR-012-按业务域分包与核心从零重写.md) 已先行占用，故本文顺延 ADR-013。

## 背景

命名与词表 v2 定稿后，四页 IA（账号 / 用量 / 记录 / 设置）页名与词表 v2 冲突，
A1-03 §4 明确标注「六页规格随阶段二落 A3-01 v2」。
[ADR-012 重写](ADR-012-按业务域分包与核心从零重写.md) 已完成 core/engine/契约
换代，前端六页 IA 是剩下的既定阶段二工作。

## 决策

1. **六页平铺**：侧栏 = **仪表盘（默认）/ 应用 / 账户 / 流量 / 日志 / 设置**，
   规范 hash = `#/dashboard`、`#/apps`、`#/accounts`、`#/traffic`、`#/logs`、
   `#/settings`（`accounts`/`settings` 沿用原链）。
2. **重定向表 v2**（7 条旧链，命中 `replaceState` 静默重写，机制不变）：
   `#/home`→仪表盘、`#/alerts`→仪表盘、`#/wallet`→账户、`#/card`→账户、
   `#/radar`→流量、`#/usage`→流量、`#/log`→日志。
3. **职责重排**：待办栏三节整体从账户页迁入仪表盘；导入入口与「一键导入（n）」
   归应用页；领取（含一键领取（n）/批量/体检）留在账户页；提醒角标改挂
   「仪表盘」项，计数口径（待处理 + 非正常账户 + 临期凭据）零变化。
4. **仪表盘三块**：今日一句话结论（原账户页 headline 谓词逐字迁入、换词）、
   TodoRail 三节、速览四行（账户健康分布 / 今日自动动作 / 流量速览 / 最近一条日志）。
   全部复用现有数据，**不新增端点**，聚合走前端 computed。
5. **应用页**：六列表（应用 / 能力 / 时间表 / 账户数 / 状态汇总 / 动作）+
   虚线邀请行「＋ 导入 {应用名}」+ 行展开跳转账户；数据全部取自契约既有
   `AppOut`（含 ADR-012 新增的 `account_ids`，只做计数展示，**不实现多账号
   操作面**——多 profile dock 取证结论见 [A2-02 §9](../specs/domain/A2-02-Connector-规范.md)）。
6. **页名词表 v2 一次到位**：账号→账户、用量→流量（域内数据语境保留「用量」）、
   记录→日志、首页→仪表盘；「卡 / 卡包 / 泊位 / 额度雷达 / 签到」语系在
   UI 文案与 `pages/` `components/` 注释中清零   （`api.ts` 分区注释属工程层，
   为保持端点零 diff 不动）；主题显示名「纸墨 / 墨夜 / 暖纸」与关于节产品名
   「AI 智能助手管家（Butler）」同步定稿。顶栏单行「AI 智能助手管家 + Butler」，
   ≤900px 顶条同样显示主名；提醒角标口径不变。
7. **影响面**：仅 `apps/web/src/` + 文档；`api.ts` 零 diff，composables 仅
   注释/动作消息换词（数据接口与端点不变），
   server / engine / connectors / sdk / mcp / desktop / cli **零改动**；
   OpenAPI 契约与 `openapi.sha256` 零 diff；不引 vue-router / pinia / 新依赖。

## 后果

**正面**：页名与词表 v2 对齐，仪表盘作为默认页回答「今天有事要做吗」，
账户页回归纯矩阵工作台；组件按页拆分后 `AccountsPage` 从 485 行降到 400 行内，
`MatrixTable` 单件承载矩阵交互，符合 conventions/4 一业务域一模块。

**负面/约束**：

- `#/usage`、`#/log` 从规范 hash 降级为旧链——已有直链不会断，但地址栏会
  静默重写为新 hash（用户可见）；书签/外部链接需接受这一变化
- 六页的「应用 / 账户」数据来自同一批端点，切换页面不额外发请求，
  数据新鲜度仍由壳的自动刷新轮询保证
- 应用页「账户数」只做展示，多账号的导入/切换操作面待连接器逐家取证后立项
