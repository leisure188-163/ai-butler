# ADR-026 · 调试端口归属校验与连接器端口可配置

- **状态**：Accepted
- **日期**：2026-11-18
- **决策者**：用户
- **关联**：ADR-007（豆包 9222 与 cdp_probe dock）/ A2-02 §8（CDP 测试边界）/ agentrouter PROTOCOL §4/§5

## 背景

平台页「导入」按 manifest 能力分发到连接器 dock。agentrouter 的网页通道把调试端口
写死 `9222`，而 9222 在本机归**豆包客户端**（ADR-007 取证）。结果：目标页未打开时
`open_page` 会在豆包客户端窗口里创建 `https://ps.air-outer.com/console` 页面并可能
拉到前台；「导入全部」按 platform_code 排序，`agentrouter` 排第一，一点就弹豆包窗口。
观感像「点接入就跳出豆包浏览器」，且等于让第三方站点跑在豆包客户端窗口里。

候选：①只改 agentrouter 常量——治不了换机器/换端口，其他网页连接器会复蹈；
②端口全部改每连接器 env——配置面变大，但归属无校验，误配仍会污染客户端窗口；
③env 可覆盖 + 使用前做端口归属校验——选③。

## 决策

**调试端口可配置 + 使用前归属校验**，流程要点：

1. 端口由连接器自持 env 覆盖，缺省值保持旧契约（agentrouter：`AGENTROUTER_CDP_PORT`，
   缺省 9222）；非法值显式报错，不静默回缺省（红线 5）。
2. 归属校验放 `web_ui` 通用底座：`require_browser_port(channel)` 读页面 target 的
   scheme，出现浏览器不可能承载的私有协议（如 `doubao://`）→ `PortNotBrowser`，
   连接器转 `BrowserPortError` 显式失败；**绝不往客户端应用窗口里开页**。
3. 校验只看 target 形状（进程归属），不看站点登录态；页面为空放行（空白/刚启动的
   浏览器由 `open_page` 按真实错误上报）。
4. `run()` 语义：端口不可用 = `FAILED`（环境问题），不转 `NO_AUTH`/relogin 待办；
   dock 语义：如实进 `DockOutcome.issues`，由「导入」结果直接展示。

**排除项**：不自动拉起/扫描备用浏览器端口（端口归属必须可预期，避免再次劫持别的
客户端）；不把 9222 从豆包手里"抢回来"——豆包主链路优先，agentrouter 需另起专用
浏览器（带 `--remote-debugging-port` 并登录站点）。

## 后果

**正面**：

- 「导入」不再把外站页面开进豆包客户端窗口；误配时给出可执行指引（env + 专用浏览器）
- 端口假设显式化：换机器/多浏览器并存只改 env，不动代码

**负面/约束**：

- 想用 agentrouter 时必须准备一个专用浏览器实例（独立 `--user-data-dir` + 调试端口），
  并保持站点登录——多一步运维
- 缺省 9222 仍与豆包冲突：不配 env 时 agentrouter 导入会稳定失败（显式报错，非静默）
