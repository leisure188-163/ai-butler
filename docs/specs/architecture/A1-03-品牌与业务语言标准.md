# A1-03 · Kabao 品牌与业务语言标准

> 状态：**生效 v1.0（2026-11-12）**　决策链：[ADR-007](../../adr/ADR-007-品牌更名Kabao与白话词表.md)
> 本文件是**品牌 / 业务语言 / 命名的唯一事实来源**：全部文档与代码以本表为准。
> 架构不变（一核多端、ADR-001/002 照旧）——重塑的是语言，不是架构。

## 1. 品牌定位

- **定位一句话**：Kabao（卡包）——本地优先的 AI 账号管家：把所有 AI 服务的账号、积分、额度、
  有效期收进一张卡包，自动领取、到期提醒、用量一目了然。
- **品类句**：「Kabao · 你的 AI 卡包」/ "Kabao · AI Card Wallet"。
- 目标用户：同时用 2 个以上 AI 工具的重度用户。
- 差异化：工程质量（协议字典 / 行为对照验收 / 审计底座）+ MCP 分发面 + 本地优先零遥测。
- 策略：**广度优先**（通用 AI 订阅管家）——先横向覆盖更多 AI 产品（R3 网页会话线），
  深度调度（网关 / 会话迁移）靠后。
- **命名尽调结论**："Kabao" 在软件品类无冲突（实体钱包品类除外）；npm `kabao`、
  PyPI `kabao` 均未占用；GitHub 组织名 `kabao` 被占（不影响自有账号下建仓库）；
  中文呈现用「卡包」，**不把「AI卡包」三字连写作注册名**（已有同类软著）。

## 2. 业务通用语言准则（四条铁律，强制）

1. **圈外秒懂**——用户可见词只用大众白话或行业通用词；
2. **一个概念一个词**——中英一一对应，禁同义漂移；
3. **隐喻只能用大众心智模型**（卡包 / 卡 / 钱包），禁止内部隐喻体系；
4. **工程术语只留代码层**（端口 / 适配器 / 六边形），绝不外溢到 UI 文案。

## 3. 两层词汇原则 + 核心词表 v1

**两层词汇**：

- **协议词汇（保留不翻译）**：Status 七字面量 `CLAIMED / ALREADY / FAILED / NO_AUTH / PENDING /
  EXPIRED / SKIPPED`——ADR-002 方言、与旧系统 oracle 对齐，是 **API 层契约**。
- **产品词汇（全量白话）**：UI 中文映射（已领取 / 今日已领 / 失败 / 需要登录 / 待处理 / 已过期 /
  已跳过）。UI 只消费 signal 分类 + 协议字面量的中文映射，不直出协议词。

**核心词表 v1**（词条 = 中文 + 英文 + 标准定义 + 禁用同义词）：

| 中文 | 英文 | 定义（标准定义） | 禁用同义词 |
|---|---|---|---|
| 卡 | Card | 一个服务 × 一个账号的权益快照（余额/有效期/状态），UI 主对象 | 泊位 |
| 卡包 | Wallet | 用户全部卡的集合，产品隐喻本体 | 港口 |
| 账号 | Account | 一个 AI 服务里的一个身份 | 泊位（账号语义时） |
| 应用 | App | 一家 AI 产品（Qoder/Trae/ChatGPT…） | 船/船队 |
| 导入 | Import | 从本机客户端/浏览器读取凭据建立账号 | 停靠 |
| 领取 | Claim | 签到/领积分/领权益的统一动作 | 补给 |
| 余额/额度 | Balance/Quota | 还剩多少（积分/次数/Token） | 舱位 |
| 用量 | Usage | 已消耗量（R2 采集对象） | —— |
| 体检 | Health check | 凭据/账号健康评估与到期检查 | 扫海 |
| 领取记录 | Claim log | 台账的用户可见名 | 航海日志 |
| 提醒 | Alert | 异常/到期/待处理通知 | 灯塔 |
| 时间表 | Schedule | 自动领取班次 | 潮汐表 |

**适用边界**：用户可见面（UI 文案 / CLI 命令与帮助 / 文档正文 / README）。
**不适用**：协议字面量、领域实体名（Account / Action / Run / Event）、
[A0-01 旧系统资产](../legacy/A0-01-旧系统知识资产.md)（描述前代项目）、git 历史。

## 4. 信息架构

- **左侧边栏导航**——理由：可扩展更多菜单，支持父子分组归类。
- **分组结构**：总览 = 首页 / 卡包 / 记录；管理 = 提醒（角标计数）/ 设置
  （父子组：通用 / 提醒规则 / 关于）。菜单名 `首页`（原「仪表盘」弃用——去工程词）。
- 页面职责：**首页** = 首屏只回答「今天有事要做吗？」（结论先行）；
  **卡包** = 卡墙主视图（卡 = 产品本体）；**记录** = 领取记录 / 台账；
  **提醒** = 异常/到期/待处理聚合。
- 页面状态走 hash 直链；详细页面规格见 [A3-01](../application/A3-01-信息架构与核心页面.md)。

## 7. 数据自动迁移（运行时行为）

- **触发**：首次运行时新数据目录无 `kabao.db` 且历史数据源存在
  → 自动搬移（连同 `-wal` / `-shm`）并改名 `kabao.db`；
  显式指定 `KABAO_DB` 时以环境变量优先、**不做搬移**。
- **安全**：历史文件**保留不删**（天然备份）；迁移幂等（新库已存在即跳过）；
  迁移动作写审计日志。迁移源优先级见 `bridge.default_db_path()`。
- **验收**：迁移测试钉死（首次迁移 / 已迁移跳过 / 显式 `KABAO_DB` 不迁移）。
