# A2-01 · 领域总纲与业务域地图

> 状态：**生效 v2.0（2026-11-14）**　决策：[ADR-012](../../adr/ADR-012-按业务域分包与核心从零重写.md)
> 本文档是 `butler_core` 的**总纲**：业务域地图、跨域公共语义（结果词汇/动作/事件/
> 端口总则）。各业务域的实体/端口/用例细则见五册分册（A2-11..A2-15），
> 包结构与依赖恒等式见 [A1-05 §2](../architecture/A1-05-按业务域重写总设计.md)。

## 1. 业务域地图

```
butler_core/
├── shared/      跨域内核：Event 六型、Status 七字面量与谓词、errors、ids
├── accounts/    账户域：Provider、Account 集合、凭据/权益/会话   → A2-11
├── execution/   执行域：Action、Run、幂等、时间预算              → A2-12
├── usage/       用量域：UsageSample、额度三型语义                → A2-13
├── health/      健康域：健康分级、风险规则、到期扫描             → A2-14
└── scheduling/  调度域：Trigger 三型、窗口、待办队列             → A2-15
```

依赖恒等式（verify 机检目标）：域 `domain.py → shared`；域 `ports.py → 本域
domain + shared`；用例可跨域读**端口**；域间禁止直接 import 对方 domain。

## 2. 账户与多账号（ADR-010 落地）

```
Workspace（本机工作区, 单实例）
 └─ Provider（AI 产品: trae_cn / qoder_cn / doubao_cn / workbuddy_cn / …）
     └─ Account（聚合根；集合——一 Provider 挂 N 个账户）
         ├─ identity: (provider, account_key)，缺省 account_key="default"
         ├─ Credential[]  凭据: kind(ss_aes/cookie/oauth/api-key) / 密文 / 有效期
         ├─ Entitlement   权益: 余额 / 连签 / 上次领取窗口
         ├─ UsageSample[] 用量: tokens_in/out / model / ts / source
         └─ Session[]     会话: 存储位置 / 可迁移级别(local|inject|server)
```

规则：
- Account 是唯一的业务标识锚点——所有 Run / Event / Sample 都挂 account_id
- Provider 是 Connector 的产品级身份，**不出现在 UI 导航**（下沉为实现细节）
- 凭据/权益/会话/用量**全部按账号隔离**，vault 内凭据绑定 account
- target 编址 = 应用 + 账号；MCP/CLI 兼容层保留裸应用 id = 首账号
- 幂等键 = `(kind, account_id, 窗口)`，采集/调度/领取全部按账号粒度

## 3. 结果词汇（单源，`shared/results.py`）

```python
class Status(StrEnum):
    CLAIMED = "CLAIMED"        # 本次执行完成领取
    ALREADY = "ALREADY"        # 本窗口已领过（幂等命中）
    NO_AUTH = "NO_AUTH"        # 凭据缺失/失效
    EXPIRED = "EXPIRED"        # 登录态过期
    FAILED  = "FAILED"         # 执行失败
    PENDING = "PENDING"        # 服务端判定暂不符合条件（如实上报，不算失败）
    SKIPPED = "SKIPPED"        # 计划内跳过（如通道不可用）

@dataclass(frozen=True)
class ResultKind:              # 分类谓词：端上渲染只消费这些
    is_pass: bool
    is_attention: bool        # 需要用户处理（进"待处理"）
    is_fail: bool
```

规则：
- 七字面量**永不改名**（ADR-002 方言、旧系统 oracle 对齐）；`from_engine(text)`
  是唯一翻译入口（legacy 自映射分支不带入新代码，oracle 对齐由测试钉死）
- 端上禁止出现 `if status in [...]` 式语义映射表（verify + 人工评审把关）
- 每个结果可携带 `repair_hint`（人话原因 + 修复动作 id），支撑"待处理 → 一键修复"

## 4. 动作模型（Action / Run，细则见 A2-12）

```
Action = (kind, target, params)
  kind: provision.run | provision.claim | usage.collect | usage.query
      | session.export | session.import | health.check | gateway.route(只读配置)

Run = 一次 Action 的执行记录
  id / action / account_id / idempotency_key / started_at / budget
  → Result(status, kind, evidence[], repair_hint?)
```

规则：
- **幂等键** = (kind, account_id, 签到窗口)——重复触发不会重复领取
- **时间预算**（budget）是 Run 的一等属性：超预算立即停止并如实上报，不静默截断
- evidence：结构化证据（原始错误码/响应摘要，脱敏后），折叠展示用
- `provision.run` 的硬承诺：`dry_run=True` 只报告不领取；Connector 不支持 →
  用例层拒绝，**绝不静默降级**

## 5. 事件（Event，单源 `shared/events.py`）

```python
# 事件 schema: {type, ts, account_id?, severity, payload}
RUN_FINISHED        # Run 终态（含 status/kind）——通知、台账、统计的统一入口
CREDENTIAL_EXPIRING # 凭据 N 天内到期
CREDENTIAL_EXPIRED
QUOTA_LOW           # 额度低于阈值（usage 域产出）
PROTOCOL_CHANGED    # Connector 探测到上游协议变化
ACCOUNT_HEALTH_CHANGED
```

规则：事件是 L0 通知中心唯一输入；severity 决定打扰级别（silent / badge / push）。
**全部成功 = silent**，只有 `is_attention` 结果才产生可见通知。

## 6. 端口总则（细则随各域 ports.py）

```python
class ProvisionPort(Protocol):            # execution 域 ports.py
    def capabilities(self) -> Capabilities: ...   # 如实申报: dry_run / 多账户 / 幂等窗口
    def run(self, req: ProvisionRequest) -> RunResult: ...
```

规则（继承六边形约束）：
- **端口随域走**：每域一个 `ports.py`，废止单一全库 ports.py（ADR-012）
- 端口签名即能力边界：签名里没有的形参 → 申报不支持 → 用例层拒绝
- 适配器（engine/connectors）不做语义决策、不解析日志文本、不维护结果映射表
- 跨域编排只经其他域的 ports（用例层组合），域 domain.py 互不 import
