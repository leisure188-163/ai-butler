## 2. 六页规格

### 仪表盘（DashboardPage，默认页）

三块，全部复用现有件，**不开新端点**，聚合走前端 computed：

1. **今日一句话结论**（原账户页 headline 谓词逐字迁入、按词表 v2 换词）：
   正在打开仪表盘 / 暂时够不到服务（副行「确认 server 已启动后点刷新」）/
   {n} 项待处理 / 还没有接入任何应用 / {总数} 个账户，{n} 个需要留意 /
   {总数} 个账户状态正常。
2. **TodoRail 三节整体迁入**：已自动完成 / 需要你处理 / 即将到期，
   含证据折叠与能力驱动的领取按钮；账户页不再挂待办栏。
3. **速览四行**：账户健康分布（ok / 需留意 / 异常，按 signal 五分类 `.tag`）·
   今日自动动作（本地自然日 runs：X 完成 · Y 未完成）·
   流量速览（最近采集于 {时间}，最低额度 {account_id}；空 →「尚未采集」）·
   最近一条日志（时间 + kind；空 →「—」）。

### 应用（AppsPage）

- 页头「应用」+ 副题「本机接入的各家 AI 助手与其能力、时间表。」+
  右侧「一键导入（n）」（n = 未导入应用数）。
- **六列表**：应用 | 能力 | 时间表 | 账户数 | 状态汇总 | 动作。
  能力文案 `provision.run→领取`、`health.check→体检`、`usage 类→用量`；
  时间表空 →「—」；账户数取契约 `account_ids`（空 →「未导入」虚线）；
  状态汇总按 signal 五分类小徽。
- 未接入应用虚线邀请行「＋ 导入 {应用名}」；点行展开能力清单 / 班次 /
  该应用账户（「去账户」跳账户页）。
- 空态「还没有应用——一键导入把本机客户端接进来。」

### 账户（AccountsPage + MatrixTable）

- 页头「账户」+「一键领取（n）」；动作结果消息行。
- **9 列矩阵**迁入 `MatrixTable.vue`：全选 / 应用 / 账户 / 状态 / 今日动作 /
  额度 / 凭据 / 最近操作 / 动作；筛选（应用 / 状态）、批量条、行展开
  `AccountDetail`、领取 / 体检按钮语义零变化。
- ≤900px 隐藏额度/凭据/最近操作三列（`.col-extra`）；不再有待办栏下沉。
- 移除：TodoRail、应用空槽邀请行、一键导入按钮、headline 谓词、
  `import`/`importAll` emits、`pending`/`todayDone`/`claimable` props。

### 流量（TrafficPage）

- 由 `UsagePage.vue` 改名（`git mv`）；页头「流量」+ 副题
  「各家账户余额、额度流水与耗尽预测。」；「立即采集」与刷新保留。
- 每账户一块：活跃包 / 进度条 / 已用·周期·状态 / 耗尽预测 / 历史包折叠 /
  用量汇总原话 / 最近流水；数据结构、forecast、progress 零变化。
- 域内数据语境保留「用量」（用量流水 / 用量汇总原话 / 暂无用量数据），
  「额度雷达」语系清零。

### 日志（LogPage）

- 页头「日志」+ 副题「操作台账——每次动作都留痕。」；
  中性表（时间 / 动作 / 应用 / 账户 / 结果）+ 结果徽 + 证据折叠；表结构零变化。

### 设置（SettingsPage）

- 三节不变：通用（主题 **纸墨（浅·默认）/ 墨夜 / 暖纸**、自动刷新、间隔）、
  提醒规则（只读常量）、关于（产品名「AI 智能助手管家（Butler）」+ 版本 +
  数据位置 butler.db + 仓库/接口文档外链）。

## 3. 组件结构与路由

```
App.vue                装配壳（持有全部 fetch/动作/轮询，页 props 入 emit 出）
├── SideNav.vue        六项平铺 + 单行品牌 + 角标在仪表盘
├── pages/DashboardPage.vue   headline + TodoRail + 速览四行
├── pages/AppsPage.vue        六列表册 + 导入入口
├── pages/AccountsPage.vue    页头 + 一键领取(n)（≤400 行）
│   └── components/MatrixTable.vue  9 列矩阵 + 筛选/批量/展开
├── pages/TrafficPage.vue     流量（原 UsagePage）
├── pages/LogPage.vue         日志（文件名不动）
├── pages/SettingsPage.vue    设置
└── components/               AppBadge / TodoRail / AccountDetail
```

- 数据流：`useShellData`（五端点并发）→ 壳 → 页 props；动作
  `useAccountActions` / `useUsageActions` 经壳 emit 下发；
  壳内新增纯派生 `claimable: Set<string>`（按 `capabilities.provision.run`），
  **composables 数据接口零新增、`api.ts` 零 diff**。
- **规范 hash**：`#/dashboard` `#/apps` `#/accounts` `#/traffic` `#/logs` `#/settings`；
  无 hash 落地 `#/dashboard`。

**重定向表 v2**（命中即 `replaceState` 静默重写，桌面壳/收藏夹直链不断）：

| 旧直链 | → 规范 hash | 说明 |
|---|---|---|
| `#/home` | `#/dashboard` | 原首页 |
| `#/alerts` | `#/dashboard` | 原提醒页 |
| `#/wallet` | `#/accounts` | 原钱包/首页 |

## 4. 渲染纪律（端零映射的 UI 落点）

- 所有结果染色/图标/文案只由 core 出产的 `kind`/signal 谓词驱动；
  组件不认识具体 status 字面量
- 不把"已请求"渲染成"已领取"（PENDING 如实展示为"服务端判定暂不符合条件"）
- 排障信息（evidence/原始响应）一律折叠进"查看详情"
- 设计 token 唯一来源 `tokens.css`（红线 6）；**身份色只允许出现在
  AppBadge**（单值点，禁止大面积色块与渐变）
- 待办栏/结论只汇报系统真做过的动作（诚实纪律）
- 可访问性地板：焦点环全控件可见、正文对比 ≥4.5:1（五色 ink 档）、
  动效尊重 `prefers-reduced-motion`、空态必给行动指引

## 5. 多账号维度（ADR-010 落地后的展示面）

- 契约已带 `account_key` / `account_ids`（apps/runs/accounts 端点）；
  `AppOut.account_id` 仍为首账号，兼容"裸应用 id"的 MCP/CLI 调用
- 应用页「账户数」列按 `account_ids` 计数展示；当前页面仍按应用聚合，
  账号维度作为数据事实存在，不新增第二层导航

  完成后，再按"应用 → 账户"展开矩阵行
