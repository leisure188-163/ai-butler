## D2 · 主题定位

- **卡纸与墨（Cardstock & Ink）**（2026-11-12 起，经设计能力包流程重定：
  frontend-design 定调 → theme-factory 专属主题 → ui-ux-pro-max 查规校验）：
  主体锚定 = **实体卡**。案面安静（冷纸灰 + 墨青），卡是唯一主角——
  真卡比例（1.586）、按应用分配的六色卡面、压印卡号（mono + text-shadow）、
  金箔芯片；领取/结果用**墨印章**形态（银行蓝印心智），印章色相由 core signal
  分类决定，不发明新语义色。
- **token 值**（唯一来源 `apps/web/src/styles/tokens.css`，红线 6）：
  - 案面 `#F1F3F4` / 卡纸白 `#FFFFFF` / 凹槽 `#E8EBED` / 纸绳线 `#D9DEE1`
  - 墨青 `#182831`（主文本与主按钮）/ 雾墨 `#54646D` / 弱化 `#84939B`（仅装饰）
  - **卡面金**：文本级 `#8A5D14`（白底 ≈4.9:1，品牌与激活态唯一彩）+
    金箔 `#C89B3C`（仅芯片/品牌符等装饰）；大胆只花在首页卡扇一处
  - 语义五色分两档（分类词表由 core 出产，UI 只消费五词）：
    填充 base 档 + 正文 ink 档（白底全部 ≥4.5:1）；卡面提亮档仅卡上用
  - 卡面身份色六值 `--card-face-1..6`（白字对比全部 ≥6:1），按应用 id 稳定散列分配
- **结构**：首页 = 卡扇（错落轻微叠压 + 载入一次揭示）；卡包页 = 应用名册行 +
  卡墙（点击卡展开体检明细）；记录 = 印形结果章 + 打印感表头；
  列表仍是「行 + 发丝线」，卡片只给卡，不做 SaaS 卡片墙
- **字体/动静**：沿用 D4 纪律（系统栈、数字 `tabular-nums`、标识符 mono）；
  动效仅两处——卡扇揭示（260ms × 60ms stagger）与按压反馈（scale 0.97/110ms），
  全局尊重 `prefers-reduced-motion`；无 ALL-CAPS 眉标/箭头按钮/渐变装饰

## D3 · 布局与 IA

- **左侧边栏导航**（2026-11-12 用户裁决，替代原五导航顶栏）：侧边栏分组——
  「总览」首页 / 卡包 / 记录 +「管理」提醒 / 设置（父子组：
  通用 / 提醒规则 / 关于）；分组能力为 R2 额度雷达、R3 网页会话等新页面留位
- 菜单定名 2026-11-12 复审：**仪表盘 → 首页**（去工程词，圈外秒懂）；
  提醒项带**角标计数**（待处理 + 非正常卡 + 即将到期，条目数不去重）
- 页面状态走 **hash 直链**（`#/home` 等）：可直链、可后退（ui-ux-pro-max 深链规则）
- 结论先行：首页首屏只回答「今天有事要做吗？」——大字结论 + 卡扇，不是横幅盒子
- 状态诚实：不把「已请求」渲染成「已领取」；结果渲染只消费 core 出产的分类谓词
- 页面规格见 [A3-01](docs/specs/application/A3-01-信息架构与核心页面.md)（按 A1-03 §4 展开）

## D4 · 字体与可访问性

- M0 用系统字体栈（-apple-system/Segoe UI/Inter 回退）；中文正文优先系统字体，不引入 webfont 延迟
- 对比度按 WCAG AA；动效尊重 `prefers-reduced-motion`

## D5 · 桌面端

- Electron（非 skill 默认 pywebview）：需要托盘常驻 + 单实例锁 + 自动拉起 sidecar；
  旧仓库的 Electron 壳验证过这条路线（只作可行性依据），新壳按本仓库结构重写
