# kabao 开发规范 · 索引

> **关系**：本目录 = kabao 项目覆写与落地约定，**自包含**。
> 冲突时：**本目录 + 架构规划文档优先**于通用模板默认值。

## 使用前必读

1. 先读 [`00-项目配置.md`](./00-项目配置.md)（唯一变量入口，模板中的 `{变量}` 由此替换）
2. 按任务类型在下表加载对应文档
3. 遵守文中 ❌ 禁止项；生成代码前过检查清单

## 快速路由

| 你要做什么 | 读哪篇 |
|-----------|--------|
| 查项目名 / 包名 / 端口 / 远端等写死值 | `00-项目配置.md` |
| 复制规范模板起一份新规范 | `01-规范模板.md` |
| 任何编码 / review（硬性红线） | `02-开发红线.md` |
| 起名 / 写 UI 文案 / 起事件与子命令名 | `03-命名与文案规范.md` |
| 生成任何 git 提交信息 | `08-提交信息规范.md`（格式 `<type>:[<需求单号>]: <中文主题>`，钩子强制校验） |

（编号稳定后不重排——外部引用按编号路由）

设计规格不在本目录：架构/领域/底座/UI 设计 → [`../specs/README.md`](../specs/README.md)。
