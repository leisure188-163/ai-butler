# butler 开发规范 · 索引

> **关系**：本目录 = butler 项目覆写与落地约定，**自包含**。
> 冲突时：**本目录 + 架构规划文档优先**于通用模板默认值。
> 编号即阅读/重要度顺序：00 变量入口 → 01 红线 → 02 命名文案 → 03 文件组织 → 04 提交信息 → 05 模板 → 06 SQL → 07 列表设计。

## 使用前必读

1. 先读 [`00-项目配置.md`](00-项目配置.md)（唯一变量入口，模板中的 `{变量}` 由此替换）
2. 按任务类型在下表加载对应文档
3. 遵守文中 ❌ 禁止项；生成代码前过检查清单

## 快速路由

| 你要做什么 | 读哪篇 |
|-----------|--------|
| 查项目名 / 包名 / 端口 / 远端等写死值 | `00-项目配置.md` |
| 任何编码 / review（硬性红线） | `01-开发红线.md` |
| 起名 / 写 UI 文案 / 起事件与子命令名 | `02-命名与文案规范.md` |
| 新增/修改路由端点 / 新建代码文件 / 评估文件体积 | `03-代码文件组织与长度约束.md`（一域一模块，600 行硬上限机检） |
| 生成任何 git 提交信息 | `04-提交信息规范.md`（格式 `<type>:[<需求单号>]: <中文主题>`，钩子强制校验） |
| 建表 / 改列 / 写域适配器 SQL / 新增迁移文件 / 生成 schema 产物 / 评审 SQL | `06-SQL规范.md`（表名列名审计字段迁移产物纪律，ADR-018） |
| 新增列表页 / 给表格加列 / 改行操作 / 评审列表 UI | `07-列表设计规范.md`（列头对齐、行操作图标化、列取舍与断点、唯一入口） |
