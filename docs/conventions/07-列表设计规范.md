# 07 · 列表设计规范

> **唯一源**：本仓库所有列表（`.matrix` 矩阵表格）以本文为准。
> 定稿依据：2026-11-19 用户逐条拍板的平台管理页（`PlatformsPage.vue` 为参照实现）。
> 冲突时：本文 > 单页 `<style scoped>` 的临时写法 > 通用表格默认。

## 1. 总原则（❌ 禁止违反）

1. **一个动作只出现一次**：同一语义在列表里只能有一个入口。「查看账户」与「去账户」、「重新接入」与「接入全部」这类同义并存一律收敛到一个。
2. **动作名不靠文字表白**：行内动作默认用图标按钮，动作名只放下方 `title` / `aria-label`，鼠标停留即可读出。
3. **表头与内容同侧**：列头文字居中时，该列内容必须一起居中；长文本列（名称、编码、能力、调度）两者都左对齐。禁止表头居中、内容左对齐的半吊子状态。
4. **窄窗口先收列，再谈滚动**：列放不下时按第 4 节断点依次收起次要列；**收列的同一条规则里必须同步放开 `min-width`**，否则收掉的列宽仍被空撑成横向滚动。
5. **颜色/字号/间距只引 `tokens.css` 变量**，禁止硬编码色值（红线 6）。

## 2. 列头与内容对齐

| 列类型 | 表头 | 内容 | 说明 |
|--------|------|------|------|
| 身份列（平台名称） | 居中 | 左对齐 | 图标 + 名称 + `›` 靠左，可控可扫读 |
| 长文本列（编码、能力、调度） | 居中 | 左对齐 | 内容本身需要整段阅读 |
| 短值列（类型、版本、状态、账户、操作） | 居中 | **居中** | 值短、居中才与表头对齐 |

实现位置：页面 `<style scoped>` 内

```css
.platform-wrap .matrix th { text-align: center; }
.platform-wrap .matrix td.col-kind,
td.col-version, td.col-state, td.col-anchor, td.col-actions { text-align: center; }
```

零散居中单元与行操作组（`.row-actions`、`.anchor-line` 都是 `display: flex`）必须让容器自己居中：`justify-content: center`。**`td` 的 `text-align` 对 flex 容器无效**——只写 `text-align: center` 会出现"表头在中央、图标在左半边"的错位。

## 3. 行操作列

- 顺序固定：**主操作（修改）→ 次操作（重新接入）→ 更多**。
- 三类都用 28×28 图标按钮：透明底、`--color-text-muted`，hover 转 `--color-accent` + `--color-accent-weak` 底，`:focus-visible` 2px 主色描边，`disabled` 透明度 0.45。
- 必须有 `title`（悬停说明）与 `aria-label`（读屏名）；两者语义不同时都写——`title` 可长，`aria-label` 用动作名。
- 图标统一经 `components/ActionIcon.vue` 渲染，禁止在各页面内联散装 SVG；新增图标先在该组件登记。
- 破坏性动作（移除、停用）不收进图标直连，放「更多」下拉里，用 `danger` 样式。

| 动作 | 图标 | title 语义 |
|------|------|-----------|
| 修改 | `edit`（铅笔） | 修改平台信息 |
| 重新接入 | `refresh`（循环箭头） | 重新连接本机客户端并重读凭据 |
| 接入（未接入平台） | `refresh` | 连接本机客户端，读取凭据并登记账户 |
| 更多 | `dots`（三点） | 更多操作 |

## 4. 列取舍与响应式断点

窗口变窄时**按优先级收列**，一次只收最不重要的一列，且同步降 `min-width`：

| 断点 | 收起 | 同时动作 |
|------|------|----------|
| ≤ 1100px | 能力 | `.matrix { min-width: 0 }`（表格回到内容自适应） |
| ≤ 900px | 调度执行时间 | 维持 `min-width: 0` |
| ≤ 720px | 类型、版本 | 维持 `min-width: 0` |
| ≤ 640px | 横向滚动关闭 | `.platform-wrap { overflow-x: visible }`；行操作转两列栅格 |

关键列（账户、操作）给固定 `width`，避免自适应把胶囊/图标压出折行（参照值：账户 112px、操作 156px）。

## 5. 可点提示（不加文字胶囊）

- 名称列进详情：名称尾部一枚极小 `›`（`--text-xs`、灰色）+ hover 时名称转主色并出下划线，**禁止**再挂「详情 ›」文字胶囊。
- 下钻入口（如账户列「查看账户」）：用描边胶囊（1px 边框 + `--color-surface-2` 底 + 主色文字），它需要比纯文字链接更明显的可点性，但也**只留一个**。

## 6. 已定稿对照（废弃 → 现行）

| 废弃 | 现行 |
|------|------|
| 名称列「详情 ›」文字胶囊 | 名称 + 极小 `›` + hover 主色下划线 |
| 「查看账户」与「去账户」并存 | 只保留账户列「查看账户 ›」胶囊 |
| 行操作「更多 ▾」文字 + 三角 | 三点图标按钮 |
| 「修改」文字按钮 | 铅笔图标按钮（hover 显示「修改平台信息」） |
| 「类型·版本」合并列 | 类型、版本各占一列 |
| 收起次要列但 `min-width: 1040px` 不动 | 收列同时 `min-width: 0`，7 列一屏可见 |
| 图标裸 SVG 内联在各页面 | 统一走 `ActionIcon.vue` |

## 7. 检查清单

- [ ] 同一动作在列表里只有一处入口
- [ ] 行操作全部图标化，每个按钮都有 `title` + `aria-label`
- [ ] 表头居中 ⇔ 该列内容居中；长文本列两边都左对齐
- [ ] 新增/收起列后 `min-width` 与断点同步
- [ ] 关键短列给了固定宽度，没有压出折行
- [ ] 颜色字号间距全部走 token
- [ ] 新增图标已在 `ActionIcon.vue` 登记，未在页面内联 SVG
- [ ] 单文件仍在 600 行硬上限内
