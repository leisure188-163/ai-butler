# 04 · 代码文件组织与长度约束

> **唯一源**：文件怎么分、多大算大，以本文为准。
> 冲突时：本文 > 上级摘要 > 通用默认。
> 缘起（2026-11-13）：server 全部 API 单文件混堆 482 行（10 端点 / 4 业务域），
> 加一个域就多一截——管理债随业务线性增长，必须结构性止损。

## 1. 总原则（❌ 禁止违反）

1. ❌ 禁止把不同业务域的端点/逻辑堆进同一文件——一业务域 = 一模块 = 一文件
2. ❌ 禁止任何代码文件超过 **600 行**（门禁机检，verify 必 FAIL）
3. ❌ 禁止往聚合器/入口文件塞业务逻辑（聚合器只做装配与 include）
4. ❌ 禁止为凑行数拆文件——拆分按职责切，切出来的每块必须能一句话说清干什么
5. ❌ 禁止把派生物/生成物当源码管（`gen/`、构建产物不受本规范约束）

## 2. 分类细则

### 2.1 服务端路由（apps/server/src/server/routes/）

| 规则 | 正确形态 | 禁止 |
|------|----------|------|
| 域划分 | 按资源/业务对象分域（accounts=卡与凭据 / apps=应用与导入 / runs=运行台账 / usage=用量雷达），域内自带投影模型与序列化器 | 按页面分域（页面会重排，域要稳定）；共享模型无归属地乱放 |
| 端点落位 | 新端点先找所属域 → 域不存在则**新建域模块** | 塞进 api.py 聚合器；为省一个文件跨域复用私有 helper |
| 聚合器 api.py | 纯 `include_router` 装配 + 一段路由纪律 docstring | 任何端点函数、投影模型、业务判断 |
| include 顺序 | 与 OpenAPI paths 首现顺序一致（契约指纹含 paths 键序——乱序 = 指纹漂移） | 随意排列导致 openapi.sha256 无谓变更 |
| tags | 各域 router 统一 `tags=["kabao"]`（当前契约口径） | 各域自造 tag 引发契约漂移；要分 tag 走正式契约再生成流程 |

### 2.2 文件长度（packages/ apps/ scripts/ 下 *.py *.ts *.tsx *.vue *.js *.mjs）

| 级别 | 阈值 | 处置 |
|------|------|------|
| 软警戒 | **400 行** | review 时必须说明「为什么不能再拆」，或列拆分挂账进 STATUS |
| 硬上限 | **600 行** | 门禁机检直接 FAIL——当场拆，不设豁免开关 |

- 排除（不计行数）：`gen/` 等生成物、`node_modules/`、`.venv/`、`__pycache__/`、`dist/`
- 文档（*.md）不进机检：文档长度是内容裁剪问题（specs 单主题纪律照旧），
  机械行数管不住废话；代码行数才是认知负载的代理指标
- 测试文件同限同规则（测试也是要读懂的代码）

### 2.3 拆分方向指引（怎么切，不是切多碎）

| 文件类型 | 拆分维度 | 反例 |
|------|------|------|
| 路由 | 按业务域（§2.1） | 按 HTTP 方法/按状态码拆 |
| usecases | 按用例（一个用例类一节，超限按用例边界分文件） | 按读写拆散一个用例 |
| adapter/连接器 | 按通道/职责（dock、usage、localenv 各自成文） | 把声明数据搬进代码文件 |
| Vue 单文件组件 | 按页面/职责成组件，超限提子组件 | 把 template 切到单独文件 |

## 3. 已定稿对照（废弃 → 现行）

| 废弃 | 现行 |
|------|------|
| server 全部端点单文件 api.py（482 行四域混堆，2026-11-13 前） | accounts/apps/runs/usage 四域模块 + api.py 纯聚合器 |
| 文件长度无约束（decl.py 551 行无感增长） | 软警戒 400 / 硬上限 600 机检（verify） |

## 4. 存量口径（不强制立即拆，但增量受约束）

> 400+ 存量是真实业务内容有机长成的，突击拆分 = 无增益 churn。规则：
> **新代码不得再堆入**，触碰相关域时顺手按 §2.3 拆。

- `packages/connectors/src/kabao_connectors/decl.py`（551 行）——声明式运行时单源，拆分随下一个通道需求走
- `packages/core/src/kabao_core/application/usecases.py`（541 行）——用例集合，超限先按用例边界分
- `packages/connectors/src/kabao_connectors/dockio.py`（521 行）——dock 扫描单域

## 5. 检查清单

- [ ] 新端点：归属域找到了吗？没有 → 新建域模块（禁止进聚合器）
- [ ] 新文件：是否过 400 行警戒？过 600 行 → 当场拆
- [ ] 路由拆分/重排后：`openapi.sha256` 指纹不变了吗（include 顺序 = paths 首现顺序）
- [ ] 拆出的模块：能一句话说清职责吗（不能 = 切错了维度）
