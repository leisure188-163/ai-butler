## 2. 技术栈

> 精确版本与升级策略 → `../specs/` 下对应设计文档，本表只放"当前值"。

| 变量名 | 当前值 | 说明 |
|--------|--------|------|
| `{stack-main}` | Python 3（uv workspace 管理） | 主语言及包管理 |
| `{stack-api}` | FastAPI | 主控 server 框架 |
| `{stack-cli}` | Typer | CLI 框架（入口 `butler`，执行器/排障用，非主入口） |
| `{stack-mcp}` | `mcp` 2.x（官方 Python SDK，MCPServer stdio） | MCP 薄壳（入口 `butler-mcp`，ADR-008） |

| `{stack-db}` | SQLite（butler.db）→ PostgreSQL（生产） | 数据库 |
| `{apiPrefix}` | `/api/v1` | 对外 API 前缀（server 路由挂载点） |
