# 03 · 命名与文案规范

> **唯一源**：本主题以本文为准。
> 冲突时：本文 > 上级摘要 > 通用默认。
> 词表与铁律的完整定义单源：[A1-03 品牌与业务语言标准](../specs/architecture/A1-03-品牌与业务语言标准.md)。

## 1. 品牌

- 英文 **Kabao** / 中文 **「卡包」**；品类句「Kabao · AI 账号管家 / AI Account Butler」
  （[ADR-009](../adr/ADR-009-矩阵重构与品类句调整.md)，2026-11-13 起；原「你的 AI 卡包」退役）。
- 不与前代项目名（auto-signin-kit）混用；「AI卡包」三字连写不作为注册名。
- 界面主对象 = **账号矩阵**（ADR-009）：「卡/卡包」保留为产品名与历史文档词汇，
  UI 不再以卡为主对象（卡面/印章等卡隐喻视觉全部退役）。

## 2. 业务词表 v1（核心词条，强制）

| 中文 | 英文 | 定义 | 禁用同义词 |
|---|---|---|---|
| 卡 | Card | 一个服务 × 一个账号的权益快照（余额/有效期/状态），UI 主对象 | 泊位 |
| 卡包 | Wallet | 用户全部卡的集合，产品隐喻本体 | 港口 |
| 账号 | Account | 一个 AI 服务里的一个身份 | 泊位（账号语义时） |
| 应用 | App | 一家 AI 产品（Qoder/Trae/ChatGPT…） | 船/船队 |
| 导入 | Import | 从本机客户端/浏览器读取凭据建立账号 | 停靠 |
| 领取 | Claim | 签到/领积分/领权益的统一动作 | 补给 |
| 余额/额度 | Balance/Quota | 还剩多少（积分/次数/Token） | 舱位 |
| 用量 | Usage | 已消耗量 | —— |
| 体检 | Health check | 凭据/账号健康评估与到期检查 | 扫海 |
| 领取记录 | Claim log | 台账的用户可见名 | 航海日志 |
| 提醒 | Alert | 异常/到期/待处理通知 | 灯塔 |
| 时间表 | Schedule | 自动领取班次 | 潮汐表 |

新词条先入 [A1-03](../specs/architecture/A1-03-品牌与业务语言标准.md) §3 再使用。

## 3. 四条铁律（❌ 禁止违反）

1. **圈外秒懂**——用户可见词只用大众白话或行业通用词；
2. **一个概念一个词**——中英一一对应，禁同义漂移；
3. **隐喻只能用大众心智模型**（卡包 / 卡 / 钱包），禁止内部隐喻体系；
4. **工程术语只留代码层**（端口 / 适配器 / 六边形），绝不外溢到 UI 文案。
