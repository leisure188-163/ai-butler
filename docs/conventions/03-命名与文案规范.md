# 03 · 命名与文案规范

> **唯一源**：本主题以本文为准。
> 冲突时：本文 > 上级摘要 > 通用默认。
> 词表与铁律的完整定义单源：[A1-03 命名与语言标准](../specs/architecture/A1-03-命名与语言标准.md)。

## 1. 产品名与词汇纪律

- 英文 **Butler** / 中文 **「AI 智能助手管家」**；产品名本身即定位句，
  不再维护第二行句式。
- 不与前代项目名（auto-signin-kit）及历史标识（Kabao/卡包——仅存于迁移兼容代码）混用。
- 界面主对象 = **账户矩阵**：「卡/卡包」等隐喻词全面退役
  （卡面/印章等卡隐喻视觉已退役，词表 v2 起词汇层同步退役）。

## 2. 业务词表 v2（核心词条，强制）

| 中文 | 英文 | 定义 | 禁用同义词 |
|---|---|---|---|
| 智能助手管家 | Butler | 产品名本体：替用户打理各家 AI 助手的管家 | 卡包 |
| 账户 | Account | 一个 AI 服务里的一个身份 | 账号、泊位 |
| 应用 | App | 一家 AI 产品（Qoder/Trae/ChatGPT…） | 船/船队 |
| 仪表盘 | Dashboard | 默认首页：今日一句话结论 + 待办栏 + 速览 | 首页（历史沿革词） |
| 流量 | Traffic | 余额/额度/用量采集与耗尽预测的页名 | 额度雷达、用量（页名级） |
| 日志 | Logs | 动作台账（runs）的用户可见名 | 记录（页名级）、领取记录（旧词）、航海日志 |
| 导入 | Import | 从本机客户端/浏览器读取凭据建立账户 | 停靠 |
| 领取 | Claim | 签到/领积分/领权益的统一动作 | 补给 |
| 余额/额度 | Balance/Quota | 还剩多少（积分/次数/Token） | 舱位 |
| 用量 | Usage | 已消耗量（**域内数据语境保留**：用量流水/已用量） | 页名级禁用（→流量） |
| 体检 | Health check | 凭据/账户健康评估与到期检查 | 扫海 |
| 提醒 | Alert | 异常/到期/待处理通知 | 灯塔 |
| 时间表 | Schedule | 自动领取班次 | 潮汐表 |

**退役禁用词**：卡、卡包、泊位、账号（→账户）、首页（页名级→仪表盘）、
记录（页名级→日志）、额度雷达（语系）、航海系全词。

新词条先入 [A1-03](../specs/architecture/A1-03-命名与语言标准.md) §3 再使用。

## 3. 四条铁律（❌ 禁止违反）

1. **圈外秒懂**——用户可见词只用大众白话或行业通用词；
2. **一个概念一个词**——中英一一对应，禁同义漂移；
3. **隐喻只能用大众心智模型**（管家 / 账户 / 应用），禁止内部隐喻体系；
4. **工程术语只留代码层**（端口 / 适配器 / 六边形），绝不外溢到 UI 文案。

## 4. 执行口径（❌ 禁止越界）

- **页名级必须换**：导航项/页标题/页副题按词表 v2；域内数据语境酌情保留
  （如「用量流水」「已用量」）。
- **连接器原始返回文本不算 UI 文案**：provider 名等数据直渲染，不扫、不翻译。
- **工程层标识不属文案**：包名/命令/env/db 文件名/存储键按 A1-03 §6 命名标准走
  （butler_* / butler / butler-mcp / BUTLER_* / butler.db / butler.settings.v1）。
- **历史文档不改写**：早期 ADR 与 A0-01 保留原词（历史标识 Kabao 仅存于迁移
  兼容代码与 A0-01）；docs/superpowers/ 历史任务书已于 2026-11-14 按用户清理要求删除。
