## 0. 执行纪律（红线级）

- **只读取证**：本地库/文件只读打开（SQLite 用只读连接或拷副本再读），绝不写
  客户端数据目录；doubao 注意 Profile N 运行期独占锁（拷副本）
- **不碰写路径**：领取/兑换/抽奖/补登类端点一律禁触（M2 不含领取扩展，2026-11-11 范围裁决）
- **不发未取证的头**：未知端点试探 = 桌面端同款最小头（鉴权 + Accept/UA）、
  只读一次、看形状即止；遇风控征兆（9074 类限流/403）立即停
- **不碰 refreshToken**（M1 既有边界）；token/凭据不进任何落盘记录——样本先脱敏
  （A2-02 §8 口径）；每条结论附取证日期 + 客户端版本号
- 拿不到/不存在 → 如实记 UNSUPPORTED/无，不猜（红线 5 精神）；顺手项与主线冲突时砍顺手项

## 1. 逐家三问（主线，四家统一）

1. **本地数据源**：客户端数据目录里与用量/额度相关的库、日志、缓存文件——
   路径、格式、只读可得性、字段形状（脱敏样例）
2. **API 用量接口**：有无用量/额度/账单类 API？鉴权能否复用 M1 已打通的凭据链？
3. **额度快照**：余额/配额/重置周期（月度重置？每日？）可得吗？——额度雷达
   「每账号还剩多少、几天后耗尽」（A1-01 §5）的输入

产出映射（spec 锚点）：字段可得性 → A2-01 UsageSample（tokens_in/out / model / ts /
source(client|gateway|api)）；余额/重置 → 额度雷达模型；通道成本与只读安全度 →
doubao CDP 结合裁决证据。
