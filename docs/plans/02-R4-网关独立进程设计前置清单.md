## 0. 执行纪律（红线级）

- **只读取证**：上游推理通道只读试探（看形状即止），领取/配置类写端点禁触
- **ToS 边界（A1-01 §6）**：L3 触碰 ToS 风险高——反代定位「个人多账户聚合，
  仅本机、仅本人账户」，不宣传不商用不共享；文档显式声明封号风险
- **不发未取证的头**；凭据/token 不落盘不进日志（样本先脱敏，A2-02 §8 口径）
- 拿不到 → 如实记 UNSUPPORTED，不猜（红线 5）；遇风控征兆立即停
- **Vault 审计是 R4 上线前的安全底线**（STATUS 既有裁决）：凭据池任何读取
  必须走 LayeredVault 同步审计路径，不得绕行

## 1. 既有锚点（汇编，实现必须落在这些约束内）

| 锚点 | 内容 |
|---|---|
| A1-01 §4 L3 | 组件链：Provider Adapter → Credential Pool → Router（余额/延迟/故障转移）→ Limiter → Meter → Audit；协议面 = OpenAI-compatible + Anthropic-compatible 两标准面；独立进程，主控管「配置与观测」、网关只管「转发与计数」 |
| A1-02 §1/§5 | apps/gateway 常驻 + 高并发独立进程；core 只有一份（纯 Python 零框架）；SQLite 单库（WAL），usage_samples 时序表按天分区 |
| A2-01 §2 | Action kind 已含 `gateway.route`（只读配置动作）；Run/Result/幂等键口径照旧 |
| A2-02 §3 | 三级扩展之三 = gateway provider 插件；**禁止声明式**；只做转发与计量（不做领取/签到编排） |
| A2-06 usage | UsageSample.source 已含 `gateway` 值——计量入账走既有 usage 通道 |
| STATUS 决策 | Vault 审计同步落账（事件总线只承载通知）；文件长度 600 行门禁适用于新进程代码 |

## 2. 设计裁决点（~~立项会话列出~~ **已全部裁决，2026-11-14 → [ADR-012](../adr/ADR-012-R4网关独立进程八项架构裁决.md)**）

- [x] **进程边界**：gateway 进程内直调 butler_core（基础设施进程非 UI 薄壳）；配置与观测走 server 契约
- [x] **主控通信形态**：HTTP（localhost），复用 server 契约 API，不发明新 IPC
- [x] **凭据池形态**：现用现取 + 短 TTL 缓存（按 provider kind 声明）；CredentialPool 端口先立，全审计
- [x] **协议面鉴权**：启动时生成随机 key + 本地配置文件（0600）；绑定 127.0.0.1，不设用户体系
- [x] **Router 最小集**：固定优先级 + 故障转移；余额感知等取证后增量
- [x] **规则引擎范围**：不做通用引擎；规则 = 声明式路由配置（模型→账户池映射），server 管理、网关只读
- [x] **Meter 口径**：优先读上游响应 usage 字段（逐调用 tokens 首次可得），缺失记请求级计数；入账 source="gateway"
- [x] **技术栈**：Python + FastAPI + httpx（异步）；将来换 Go/Rust 只换此进程

## 3. 取证清单（主线：各连接器的推理/对话通道形状）

> M1/M2 只打通了签到与用量；**反代的上游 = 各家的推理通道，目前零取证**。
> 与 M2 同构的逐家三问：

1. **推理通道形状**：各家有无推理/对话 API（或仅界面通道）？端点/鉴权
   （能否复用 M1 凭据链）/请求体/流式形状
2. **并发与风控边界**：账户级并发限制、限流特征、封号风险信号（只读试探）
3. **额度扣减语义**：推理调用如何扣 credits/额度（与 R2 余额快照衔接 → Router 输入）

- [x] **trae_cn（mac 资源串侧已取证，2026-11-14）**：`api.trae.com.cn` +
      `api/ide/v1/llm_raw_chat`(v1/v2) + `x-ide-token`；自带多协议 llm-client
      （OpenAI/Anthropic 双形 + usage 结构）+ `check_estimated_balance`——
      **反代上游候选一号**；请求体/头组/流式形状待 Windows 运行态验证
      （PROTOCOL §9）
- [x] **qoder_cn（mac 资源串侧部分）**：域 = `api.qoder.com`（M1 同域）+

- [x] **doubao_cn（mac 侧结论）**：CDP UI 驱动转发可行（ADR-007 通道），
      但发消息 = 写动作禁触取证——最终验证归 G5 且需用户授权发测试消息

      credits 侧（PROTOCOL §9）

## 4. 阶段拆解建议（裁决 + 取证回收后细案）

| 阶段 | 内容 | 出口 |
|---|---|---|
| G0 | 本清单裁决点逐条出 ADR + 取证 spike 回收 | ADR 集 + PROTOCOL 推理通道小节 |

## 5. 明确不在 R4 范围（防蔓延）

- 会话迁移（R5）；成本顾问/套餐对比（L6）；共享账户/转售（合规红线）
- 连接器新增家数（广度扩张不与 R4 混批）
- 领取类扩展（doubao 任务清扫 / workbuddy 成长中心——另立小批次，M2 既有裁决）
