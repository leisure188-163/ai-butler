# M2 用量取证清单 · 真机 spike 任务书

> M2 立项已裁决**先真机取证 spike，spec 按实况落盘**（STATUS 2026-11-11 裁决点 1）。
> 四家连接器的用量数据源 = 零取证（旧仓库只有签到知识资产，无用量线索）——
> 本清单是 **Windows 真机会话的任务书**；产出回填各连接器 PROTOCOL.md
> 「§用量取证」小节 + 汇总 §6 可得性矩阵，作为 M2 spec 三件事的输入：
> A2-01 UsageSample 落地字段 / 额度雷达数据模型 / doubao CDP 结合裁决（ADR-007 遗留）。
> 清单由 mac 侧立项会话制定（2026-11-11）；执行会话：Windows 真机侧。

## 0. 执行纪律（红线级）

- **只读取证**：本地库/文件只读打开（SQLite 用只读连接或拷副本再读），绝不写
  客户端数据目录；doubao 注意 Profile N 运行期独占锁（拷副本）
- **不碰写路径**：领取/兑换/抽奖/补登类端点一律禁触（M2 不含领取扩展，2026-11-11 范围裁决）
- **不发未取证的头**：未知端点试探 = 桌面端同款最小头（鉴权 + Accept/UA）、
  只读一次、看形状即止；遇风控征兆（9074 类限流/403）立即停
- **不碰 refreshToken**（M1 既有边界）；token/凭据不进任何落盘记录——样本先脱敏
  （A2-02 §8 口径）；每条结论附取证日期 + 客户端版本号
- 拿不到/不存在 → 如实记 UNSUPPORTED/无，不猜（红线 5 精神）；顺手项与主线冲突时砍顺手项

## 1. 逐家三问（主线，四家统一）

1. **本地数据源**：客户端数据目录里与用量/额度相关的库、日志、缓存文件——
   路径、格式、只读可得性、字段形状（脱敏样例）
2. **API 用量接口**：有无用量/额度/账单类 API？鉴权能否复用 M1 已打通的凭据链？
3. **额度快照**：余额/配额/重置周期（月度重置？每日？）可得吗？——额度雷达
   「每账号还剩多少、几天后耗尽」（A1-01 §5）的输入

产出映射（spec 锚点）：字段可得性 → A2-01 UsageSample（tokens_in/out / model / ts /
source(client|gateway|api)）；余额/重置 → 额度雷达模型；通道成本与只读安全度 →
doubao CDP 结合裁决证据。

## 6. 可得性矩阵（spike 后填，M2 spec 数据模型输入）

> 执行完成（2026-11-12，Windows 真机；客户端版本见各连接器 PROTOCOL §7）。

| 连接器 | 本地源 | API 源 | UsageSample 字段可得 | 余额/重置 | 鉴权复用 | 建议主通道 |
|---|---|---|---|---|---|---|
| trae_cn | state.vscdb 横幅键（月度重置旁证）；逐调用无 | ide_user_ent_usage：聚合 usage_summary + 29 包分账本 | tokens/model/逐调用：**双 UNSUPPORTED**；consumed/ratio 聚合可得 | 套餐 500/月月度重置（实证）+ 签到包 31 天滚动 | ✓ SS_AES→Cloud-IDE-JWT | API ent_usage |
| qoder_cn | main.sqlite 上下文占用仪表（非计费）；逐调用无 | v2/me/usage：percentage + userQuota + addOnQuota | 同左**双 UNSUPPORTED**；percentage 聚合可得 | addOn 2300 **无重置**（9999 占位）；userQuota 当前无 | ✓ DPAPI→Bearer+机器头 | API v2/me/usage |
| doubao_cn | IndexedDB 上下文占用（非计费）；credits 无存储 | quota/records 入账流水 + detail 面额 | **双 UNSUPPORTED**；入账 ledger 可得 | **无余额/消耗 API**；UI 只展示累计获得 | ✓ 零凭据 CDP 现取 | API records + detail；CDP 不做用量 |
| workbuddy_cn | 无（本地 UNSUPPORTED） | get-user-resource：85 包分账本 + payment-type | **双 UNSUPPORTED**；逐包 used/remain 可得 | 逐包 CycleEnd 月度；TotalDosage=活跃剩余合计 | ✓ $wbEncrypted→Bearer | API get-user-resource |

**四家共同结论**：UsageSample 本义（逐调用 tokens_in/out / model）**双通道全
UNSUPPORTED**——M2 spec 的用量采集需按「聚合用量 + 额度余额快照 + 入账流水」
三型重定义；额度雷达（余额/耗尽日期）四家 API 通道全可得；doubao CDP 裁决
材料齐（§4，倾向不做 CDP 读用量）。
