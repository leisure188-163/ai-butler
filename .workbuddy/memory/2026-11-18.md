### 00:40 紧急修复：全主题布局塌陷（:root 被 CSS 解析丢弃）
- **现象**：用户反馈"所有布局坏了、切主题也坏"。侧栏塌成 756px、KPI 卡高度塌陷文字重叠、间距字号全失效。
- **根因**：tokens.css 顶部注释块第 11 行 `*/` 提前闭合后，12-15 行残留裸文本 + 一个游离 `*/`，CSS 解析器把后续 `:root{...}` 整块当错误吞掉 → `--sidebar-w`/`--space-*`/`--text-*` 等基础尺寸全空。切主题只换颜色救不回尺寸，故全主题皆坏。
- **修复**：删掉重复/游离的注释残行，`:root` 恢复注册。验证 `rootRuleCount 0→1`、sidebarW `''→216px`、space6 `''→24px`；四主题（qinglan/mist/dark/paper）截图全部布局正常；vue-tsc/build 通过。
- **教训（重要）**：改 CSS 顶部块注释时，务必确认只有一对 `/* */`；游离 `*/` 或注释外裸文本会静默吞掉紧随的规则，且不会报 TS/构建错、浏览器也无控制台报错——只能靠 computed style 抓变量空值定位。改完 token 块应做一次 `--sidebar-w` 等基础变量的非空校验。
